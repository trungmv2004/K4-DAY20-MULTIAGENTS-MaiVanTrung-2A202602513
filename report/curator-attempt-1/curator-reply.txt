=== SKILL: preprocess_raw_data_consistently ===
---
name: preprocess_raw_data_consistently
description: Use when you receive a raw CSV or similar dataset that may contain duplicates, missing values, or inconsistent formatting.
---
- Read the entire file into a structure while preserving the original row count for later reporting.
- Deduplicate records using the primary key (e.g., `order_id`), keeping the first occurrence and incrementing a duplicate counter.
- Trim leading/trailing whitespace from all string fields; apply a canonical case (e.g., title case) to categorical values like `region`.
- Parse date/time strings into UTC datetime objects: attempt ISO‑8601 with `T`, then `YYYY-MM-DD`, then `DD/MM/YYYY`; raise an error if none succeed.
- Treat a designated sentinel value (e.g., `-999`) as a missing amount; exclude such rows from numeric sums but count them for missing‑amount metrics.
- Write the cleaned, deduplicated rows to the required intermediate file (e.g., `clean.csv`) using the exact column order: `order_id,timestamp_utc,region,amount_cents`.
- Log key statistics: total rows processed, duplicates removed, missing amounts encountered, and any other metrics needed for the final answer.
